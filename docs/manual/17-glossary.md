# Glossary
<!--blurb: Short definitions of every term and abbreviation used on the screen.-->

## Terms

| Term | Meaning |
| --- | --- |
| **ACCENT / ACC** | a louder step; with [[OCT+]] held, tap a step to toggle it. |
| **ACID** | the 303-style bass model; at most two tracks. |
| **ACCEL** | knob acceleration (MENU). |
| **ARP** | the button that opens Grids. |
| **BANK** | 16 steps; a track has up to four. |
| **BDTRX... SHTRX** | the TRX models of the MD bank (see Sounds). |
| **CHOKE** | choke group 1 to 4: hits cut others in the group. |
| **CLK** | clock source: INT, USB, TRS, BLE, LINK. |
| **COMP** | the compressor. **GHOST** is its handling of a muted source (MUTE, KEEP, HIDE). |
| **DEST** | the LFO routing page: four slots of source, destination and depth. |
| **DIV** | a track's step division. |
| **E0 to E7** | a model's eight SOUND knobs. |
| **ENV** | the button that toggles STEPS / TRACKS mode. |
| **FILL** | a step flag; plays only during a fill (hold REC off SEQ). |
| **FM-Link** | two FM-1s in time over Bluetooth. |
| **GO action** | a TOOLS / PROJECT knob that needs two detents within 1.5 s. |
| **Grids** | Mutable Instruments' drum pattern generator (MAP or EUCL). |
| **KEYF** | RESON KEYFOLLOW: the ring follows each hit's note. |
| **KEYS** | the keys play the selected track chromatically ([[SCL]]). |
| **LAYER** | a sample layered under any model. |
| **LOCK** | a per-step value for a knob (parameter lock). |
| **MAP / EUCL** | Grids modes. |
| **MD / MODERN / CLASSIC** | the three sound banks. |
| **MOTION** | recorded knob turns. |
| **NOTE** | the MIDI note a track answers to. |
| **PERFORM** | live master effects while [[FX]] is held. |
| **PRIO** | HIGH or LOW voice priority. |
| **PROB** | a step's probability. |
| **RATCH** | a step's ratchet repeats (1 to 4). |
| **RESON** | the resonator insert (STRNG, PIPE, CHORD, MODAL). |
| **ROUT** | MIDI-in routing: NOTE, SEL, TRACK. |
| **SCL** | the button for KEYS (SEL on the simulator). |
| **SLICER** | the GATE / STUT pattern insert. |
| **SLIDE / TIE** | legato glide and held note on ACID steps. |
| **SMC-Mixer** | M-VAVE's Bluetooth mixer, used in DAW mode. |
| **SRC** | the source of a track's steps (STEP or a Grids lane), an LFO slot's source, or COMP's key track. |
| **STEPS / TRACKS** | ENV mode: the keys are steps, or play tracks. |
| **SYNC** | MIDI clock out. |
| **THRU** | pass MIDI from each input to the other outputs. |
| **THROW** | PERFORM macro that sends the dry mix into the delay and reverb. |
| **USR1 to USR3** | user sample slots. |
| **Safe start** | hold SEQ at power-on: loads nothing; USB updates still answer. |

## Panel abbreviations

HOME, EDIT, SEQ, FX, ARP, LFO, ENV, SCL, GLO, SAVE, PLAY, REC, OCT-, OCT+, SELECT, ALGORITHM, PRESETS, MASTER and KNOB 1 to 4 are described under *The panel*. White keys are named by note: F3 to F4 are the eight track keys (tracks 1 to 8); F3 to G5 are the 16 step keys.

## Note names on the keys

| Key | Note |
| --- | --- |
| white keys, steps 1 to 16 | F3, G3, A3, B3, C4, D4, E4, F4, G4, A4, B4, C5, D5, E5, F5, G5 |
| black keys | F#3, G#3, A#3, C#4, D#4, F#4, G#4, A#4, C#5, D#5, F#5 |
| PERFORM effects | F#3 REPEAT 1/8, G#3 REPEAT 1/16, A#3 REPEAT 1/32, C#4 REVERSE, D#4 TAPE STOP, F#4 LPF, G#4 HPF, A#4 FREEZE, C#5 OCT UP, D#5 OCT DOWN (F#5 does nothing) |
| MUTE screen | track keys F3 to F4; top C# `MUTE: NOW`; top D# `MUTE: NEXT BAR`; G4 MIDI LEARN |
