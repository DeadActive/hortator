# FM: a 2-operator FM percussion model — design

Date: 2026-10-08. Branch `fm` from `filter` (main `drum-v0.13.0` + COWB, FILTER, the PERFORM knobs fix, the step
keys; none merged yet). Second of the user's three parts (filter, FM percussion, the melodic part). No frozen file
changes.

## 1. Goal and user decisions

One drum model for bells, metallic toms, woodblocks and zaps (and FM kicks). User decisions (2026-10-08):
- **Approach A:** one model, 2 operators + feedback (not upstream's 4-operator DIGITAL, not several fixed models).
- The knobs as in §2 (approved as presented).

## 2. The model

`FM` (`DM_FM`), appended after MEMB (stored model numbers unchanged). Per hit:
- carrier: a sine at the pitch; modulator: a sine at RATIO × the pitch, its output added to the carrier's phase
  × INDEX × the FM envelope (full at the hit, falling over MDEC);
- SWEEP: the same envelope raises the pitch at the hit (up to SWEEP semitones), falling back to TUNE;
- FBK: the modulator's own output fed back into its phase (grit .. noise);
- the amplitude falls over DECAY; VEL: how much the hit's velocity (accent 127, plain 96, MIDI) adds to INDEX.

| Knob | Range | Default | Notes |
|---|---|---|---|
| TUNE | ±24 semitones around A3 (220 Hz) | 0 | |
| DECAY | 0..127 = 5 ms .. 4 s | 50 | amplitude (dm_dsp.c DECAY_K) |
| INDEX | 0..127 = FM depth 0 .. ~8 | 60 | 0: a pure sine |
| RATIO | 16 steps: 0.5 1 1.41 1.5 2 2.76 3 3.5 4 5.4 6 7 8 9.2 11 14 | 1.41 | shown as the number |
| MDEC | 0..127 = 2 ms .. 2 s | 40 | the FM envelope (INDEX and SWEEP) |
| SWEEP | 0..127 = 0 .. 48 semitones | 0 | the pitch drop |
| FBK | 0..127 | 0 | the modulator's feedback |
| VEL | 0..127 | 64 | velocity / accent → INDEX, centred at a plain step (96: plays INDEX; user, 2026-10-08) |

- 2 voices per track (a ringing bell is not cut by the next hit), weight 1 each.
- Level at the defaults within ±3 dB of TOM's.
- Cost: 2 sines + 2 envelopes per sample per voice (~ a TOM voice).

## 4. Testing (host, failing first)

- Pitch: INDEX 0 → a pure sine at TUNE (no sidebands); TUNE ±12 → an octave.
- FM: INDEX up → sidebands at f ± RATIO·f (an inharmonic RATIO: inharmonic partials); more INDEX, more sideband energy.
- MDEC: the sidebands fade (early brighter than late); MDEC 0 vs 127 far apart.
- SWEEP: the pitch starts ~SWEEP semitones higher and settles on TUNE.
- FBK: up → a noisier spectrum (spectral flatness rises).
- VEL: an accent brighter than a plain hit.
- Every knob at min / mid / max: bounded, ends (voice off, track idle).
- Level within ±3 dB of TOM at the defaults; golden hash for FM added (the others unchanged).
- WAVs: bell, metallic tom, woodblock, zap, FM kick; screens: SOUND 1/2, 2/2.
- Firmware: H2 0 different, stack, loader, no divdi3, check_untouched; a budget line for the FM render function
  (the number for the user's approval); the host cost suite within its limits (asking before any change).
