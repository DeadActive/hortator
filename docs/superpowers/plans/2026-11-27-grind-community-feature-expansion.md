# GRIND MACHINE Community Feature Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Add the nine user-selected CoralFlower/FRASIL-inspired capabilities to GRIND MACHINE without delaying its first usable hardware alpha.

**Architecture:** Keep Hortator's eight native tracks, cue controller, portable deterministic generator, native mixer, storage and panel ownership. Extend the existing P05–P09 contracts with small, independently reviewable changes; do not import a second scheduler, audio engine, HAL, loader or application shell. Render the same C firmware in the existing host and WASM fixtures.

**Tech Stack:** Existing C99/gnu11, fixed-point audio, JieLi PI32v2 native builds, native IRQ guards, existing shell/Python/Node test runners, Emscripten, GitHub Actions.

## 1. Scope, decisions and source evidence

Approved selection (2026-11-27): A1 Style Browser with pattern preview; A2 per-style kit and morph settings; A3 natural drum-hit variation; A4 7/4 for Mathcore; B1 ANCHOR and RETURN; B2 Scene Morph; B3 Master SINK, CUT and SWELL; B4 COMPARE; B5 UNDERGROUND FX (Tape, AM, Phone).

Explicitly excluded: screen mirroring/remote control, GRIND ORGANISM, selective project restore, performance recording. Also no VINYL, full CLOUD/Shimmer/Freeze port, additional LFO cascades, chord/lead engines, extra device models or Bluetooth scope in this plan. Existing native equivalents remain available. No new release certification, quantitative threshold or global gate. Apply the user-approved community quality policy of the [original plan](2026-11-27-grind-machine-implementation.md#community-quality-policy-user-approved-direction-revision-11).
