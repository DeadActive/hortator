# Fixes after 0.16.0 — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the nine user fixes of 2026-10-11 (spec below): SELECT turns pages, HOME's TRACKS / HOME modes, REC arms
anywhere, the GLO-held MUTE screen, the last project loaded at power-on, PERFORM knob effects that stay on, a
metronome, 95 % CPU shedding with per-track priority, and the overload icon.

**Architecture:** all in the core unit (felucca.c's includes); no BLE unit change except the BT page's knob (SELECT).
The project format moves to FDRC for `P_PRIO`. Device settings use spare bits of the existing record.

**Spec:** `docs/superpowers/specs/2026-10-11-fixes-design.md` (the authority; read it first).

**Plan form:** like the MIDI plan: exact behaviour, interfaces and tests per task; the code is the implementer's;
each task is reviewed.

## Review focus

1. Keys pressed in the same frame as GLO / while the MUTE screen is up must never play or record a drum (the ISR's key
   routing), and releasing GLO with a key still held must not leave a stuck note or a stuck UI mode.
2. HOME mode switching with the PERFORM layer, the menu, a confirm, KEYS, step record and Grids tracks: no screen left
   in a state its keys/LEDs don't match.
3. The boot auto-load runs before audio and interrupts are on: no `fm1_irq_on` before the HAL expects it; a load that
   fails or a slot that is corrupt never blocks the boot; safe start skips it.
4. FDRC conversion: every older format loads with PRIO HIGH, RAM slot images left by 0.16.0 (FDRB, smaller) are
   refetched from flash or converted, never misread.
5. The metronome click's timing with external clock, swing and a song chain; no click while stopped; its cost inside
   the audio ISR.

### Task 5: metronome

**Files:** `fx.c` (the click generator mixed after the master level, before `perf_block`), `seq.c` (a beat flag of its
own from `gclk`: quarter = `cnt % 4 == 0`, bar = `cnt % 16 == 0`, sample offset in the block), `core.h` (`G_METRO`

levels LOW / MID / HIGH ≈ −24 / −15 / −6 dBFS peak; starts at the beat's sample offset within the block.
