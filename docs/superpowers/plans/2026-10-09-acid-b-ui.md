# ACID plan B (KEYS mode, live and step record, the piano roll) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** an SCL tap turns the 27 keys into a chromatic keyboard of the selected track (KEYS): drums hit
transposed, ACID plays mono with last-key priority, slides and a gate held by the key; OCT- / OCT+ shift it by
octaves. Armed and playing, the keys record notes, ties and slides; on the STEP page with the transport stopped, a REC
tap starts step record. An ACID track's STEP page is a piano roll, transposed drum steps are marked, the footer shows
the step's note, ACID's SOUND page its filter and envelope; the screenshots go to the user.

**Architecture:** the keys' presses become hits in the audio ISR (`seq.c keyboard_block`, before each block). KEYS
is a fourth owner of them, `song.seq_mode` 3, which the UI sets each frame from `keys_mode()` (`ui.c`). The ISR side
is small: a one-key state `kz` and three noinline functions (`keys_on`, `keys_off`, and for live record `keys_rec`,
`keys_tie`). A drum is hit through `drum_play(t, 100, nt)`; ACID is mono through the plan A hooks: a key pressed
while the last one sounds `glide`s, a key's gate has no countdown (`gate_n` 0, which the sequencer's rests and TIEs
leave alone) and `keys_off` closes it. Live record reuses `rec_hit` (the nearest step) and writes TIE at each later
step's middle while the key is held. Step record is UI-only (`ui_input.c`, `ui.srec`): it writes steps while the
transport is stopped; the ISR still sounds the keys. Drawing (`ui_draw.c`): `head_mode` (top bar), `graph_roll`
(gated model on STEP), a mark on transposed drum steps, `foot_note`, `graph_acid`. The ratchet keeps its note in
`t->rat_nt` (plan A's review ruling).

**Tech Stack:** C (pi32v2 clang, integer only, `-Os`), the host test harness (`tests/drum_host.h`,
`tests/ui_host.h`: `keys()`, `press()`, `turn()`, `ui_frame()`, `shot()` PPM -> PNG in `run_drum_tests.sh`).

**Spec:** `docs/superpowers/specs/2026-10-09-acid-design.md` (§5 KEYS, §6 recording, §7 display, §8's keyboard /
recording lines; §2's note of a new step)

## Spec gaps: rulings (from the code)

- **OCT- / OCT+ already have page jobs** (the STEP grid's bank, LAYER from EDIT, the LFO pages' mode / LFO 2). With
  KEYS on they are the octave wherever KEYS has the keys (spec §5 names no exception); the bank stays on KNOB 1
  (STEP), LAYER / LFO 2 need KEYS off; TRACKS (not KEYS) keeps OCT as its bank.
- **Pages:** KEYS has the keys everywhere but TRACKS and COMP (+ NAME, the menu, FX held): the global pages too
  (today their keys are a plain drum pad; one rule, and the top bar says KEYS).
- **MIDI out:** KEYS sends none (the drum channel's notes mean tracks: a chromatic note would hit other tracks on a
  chained device). A key's release still sends today's note-off, as on the STEP grid.
- **Mono release:** last key wins; letting go of an older key does nothing; letting go of the sounding key closes the
  gate (no return to a key still held). A key held 5.5 s meets plan A's backstop (`ACID_LIFE`): the gate closes.
- **Live record on a drum track:** ON + NOTE only; TIE / SLIDE are written on gated (ACID) tracks only (a TIE step on
  a drum plays nothing: holding a drum key would erase the steps it crosses).
- **The sequencer and a key on one ACID voice:** a step's ON restarts the voice (the sequencer takes it over, its
  gate counts); rests and TIEs leave a key's gate alone; the key's release then leaves the sequencer's gate.
- **Step record:** a key keeps the cursor step's ACC / SLIDE as FLAG set them (FLAG first, then the note); the
  cursor wraps at LEN; KNOB 1 with a key still held: its release moves nothing; another track ends step record.
- **"ACC a full-height mark"**: as upstream's roll: the accented bar fills its row (WHITE), a plain one is 2 px.
- **Top bar:** `KEYS F3` replaces `SONG n` while KEYS is on (the SONG page shows the row); `STEP REC 05` moves `T1`
  to x 168.
- **Footer:** "the held step" = a grid key held (KEYS off); KEYS' held key lights its row on the roll's keyboard
  strip instead. With a note shown, the title drops its `n/m`.
- **§2 new-step note** applies to every track (literal): a drum's new step gets its last KEYS note (0 until KEYS
  played it).

/* an SCL tap turns KEYS on (its LED, the top bar KEYS F3) and off; the 27 keys play the selected track chromatically
 * (a drum transposed: nt = NOTE - 60, F3 = 53); OCT- / OCT+ shift by an octave, -2..+2; KEYS selects no track */
static void test_keys_map_oct(void)
{
    char b[16];
    uint32_t k, a, ok = 1;
    ui_host_init();
    tap(B_SCL);
    check("KEYS: an SCL tap turns it on: the SCL LED lit, the top bar KEYS F3, the keys KEYS' (seq_mode 3)",
          ui.keys && led_on(panel.btn[B_SCL]) && head_mode(b) && str_eq(b, "KEYS F3") && song.seq_mode == 3u);
    for (k = 0; k < 27u; k++) {
        a = hit_age(&trk[0]);
        keys(1u << k);
        ui_frame();
        keys(0);
        ui_frame();
        ok &= hit_age(&trk[0]) != a && trk[0].nt == (int32_t)k - 7;
    }
    check("KEYS: key k (0 = F3) hits the selected drum transposed to NOTE 53 + k (nt k - 7), every key", ok);
    check("KEYS: the keys select no track (HOME)", song.sel == 0);
    tap(B_OCTUP);
    tap(B_OCTUP);
    tap(B_OCTUP);
    keys(1u);
    ui_frame();
    keys(0);
    ui_frame();
    check("KEYS: OCT+ three times: +2 octaves at most (F3's key plays F5, nt +17), KEYS F5, OCT+ lit",
          song.octave == 2 && trk[0].nt == 17 && head_mode(b) && str_eq(b, "KEYS F5") && led_on(panel.btn[B_OCTUP]));
    for (k = 0; k < 5u; k++)
        tap(B_OCTDN);
    keys(1u);
    ui_frame();
    keys(0);
    ui_frame();
    check("KEYS: OCT- five times: -2 octaves at most (F1, nt -31), KEYS F1",
          song.octave == -2 && trk[0].nt == -31 && head_mode(b) && str_eq(b, "KEYS F1"));
    tap(B_SCL);
    keys(1u << KEY_TRK_KEY[3]);
    ui_frame();
    keys(0);
    ui_frame();

/* ACID under KEYS: mono, the last key wins; held: the gate stays open past GATE; a key over the sounding one slides
 * (same voice); the sounding key's release closes the gate, an earlier key's does nothing */
static void test_keys_acid_mono(void)
{
    track_t *t = &trk[0];
    uint32_t age, k;
    ui_host_init();
    drum_set_model(t, DM_ACID);
    tap(B_SCL);
    keys(1u << 7);                                   /* C4 */
    ui_frame();
    age = t->v[0].age;
    check("KEYS, ACID: a key starts its note (C4), the gate open",
          t->v[0].active && (t->v[0].x[2] & 1) && t->v[0].x[1] == 60 * 16);
    for (k = 0; k < 400u; k++)                       /* 400 blocks, 290 ms: well past GATE (half a 1/16) */
        ui_frame();
    check("KEYS, ACID: held past GATE the gate stays open (the key holds it)", (t->v[0].x[2] & 1) != 0);
    keys(1u << 7 | 1u << 12);                        /* F4 over it */
    ui_frame();
    check("KEYS, ACID: a key over the sounding one slides to it (same voice, no restart)",
          t->v[0].age == age && t->v[0].x[1] == 65 * 16 && (t->v[0].x[2] & 1));
    keys(1u << 12);                                  /* C4 (no longer sounding) let go */
    ui_frame();
    check("KEYS, ACID: an earlier key let go: the note goes on", (t->v[0].x[2] & 1) != 0);
    keys(0);
    ui_frame();
    check("KEYS, ACID: the sounding key let go: the gate closes", !(t->v[0].x[2] & 1));
    keys(1u << 9);                                   /* D4 after all were let go */
    ui_frame();
    check("KEYS, ACID: a key after all were let go starts a new note", t->v[0].age != age && t->v[0].x[1] == 62 * 16);
    keys(0);
    ui_frame();
}

static void srec_note(uint32_t key)                    /* a key pressed: its note on the cursor step */
{

static void srec_knob(uint32_t k, int32_t s)
{
    track_t *t = TSEL;

        ui.bank = (uint8_t)(ui.sr_cur / 16u);
        ui.sr_key = 0;                                 /* a key still held moves nothing on its release */
        return;
    }
    st = &t->step[ui.sr_cur];
    if (k == 1u) {
        st->nt = (int8_t)clamp(st->nt + accel(EN_K2, s, NT_MAX - NT_MIN), NT_MIN, NT_MAX);

        st->on = v == 0;
        st->tie = v == 1;
    } else {

        st->acc = (uint8_t)(v & 1);
        st->slide = (uint8_t)(v >> 1);
    }
}

/* STEP page, a gated model's track (ACID; spec §7, after upstream Felucca's graph_roll): a piano roll of the bank's
 * 16 steps. PR_ROWS semitone rows of PR_RH px, the highest on top; the C rows named on the left (C4 = NOTE 60) and
 * closed by a DIM line, beside a keyboard strip (the key sounding on this track: its row WHITE); step lines LINE, the
 * beats DIM. A note is a 9 px bar on its row (ACC: WHITE, the row's full height; else HI, 2 px), a RATCH step's in its
 * 2..4 parts; a TIE carries the bar of the note before through its column (from the step line: one long bar); a rest
 * is empty; SLIDE an AMB line from the bar's end into the next note (not out of a ratcheted step). A note outside the
 * view: a 1 px mark on the edge row. Step record's cursor: a WHITE frame; the playhead: a 1 px WHITE line. The view
 * (proll.lo, the bottom row's note) is roll_view's (graph_signature) */
#define PR_ROWS 24                                      /* 2 octaves */
#define PR_RH 4                                         /* px per row */
#define PR_Y0 2                                         /* the top row (graph y) */
#define PR_X0 34                                        /* the first step column */
#define PR_CW 12                                        /* px per step */
#define PR_KX 22                                        /* the keyboard strip, 9 px */
static struct { uint8_t lo, trk; } proll;               /* the bottom row's note; the track it is for + 1 */
static const uint8_t KEY_BLACK[12] = {0, 1, 0, 1, 0, 0, 1, 0, 1, 0, 1, 0};

static int32_t pr_row_y(int32_t n) { return PR_Y0 + ((int32_t)proll.lo + PR_ROWS - 1 - n) * PR_RH; }

/* the step whose note sounds at si: si when ON, the ON step before a run of TIEs (NSTEP: none) */
static uint32_t pr_src(const track_t *t, uint32_t si, uint32_t len)
{
    const step_t *st = seq_steps(t);
    uint32_t k;
    for (k = 0; k < len && st[si].tie; k++)
        si = (si + len - 1u) % len;
    return st[si].on && !st[si].tie ? si : NSTEP;
}

/* the view: the bank's notes centred, kept while they fit; wider than the view: step record's cursor note (else the
 * lowest) in the middle; no notes: the track's last key note */
static void roll_view(const track_t *t)
{
    const step_t *st = seq_steps(t);
    uint32_t i, len = view_len(t), base = ui.bank * 16u;
    int32_t lo = 127, hi = -1, n, cur = proll.lo, tgt;
    for (i = 0; i < 16u && base + i < len; i++)
        if (st[base + i].on && !st[base + i].tie) {
            n = 60 + st[base + i].nt;
            lo = n < lo ? n : lo;
            hi = n > hi ? n : hi;
        }
    if (hi < 0)
        lo = hi = 60 + t->key_nt;
    if (hi - lo < PR_ROWS)
        tgt = proll.trk == song.sel + 1u && lo >= cur && hi < cur + PR_ROWS ? cur : (lo + hi + 1) / 2 - PR_ROWS / 2;
    else
        tgt = (ui.srec ? 60 + st[ui.sr_cur % NSTEP].nt : lo) - PR_ROWS / 2;
    proll.lo = (uint8_t)clamp(tgt, 0, 128 - PR_ROWS);
    proll.trk = (uint8_t)(song.sel + 1u);
}

/* a note's bar at row y in `hits` parts 1 px apart (RATCH; 1: whole); out of the view: a 1 px mark on its edge */
static void pr_bar(int32_t x, int32_t y, int32_t w, int acc, uint16_t c, uint32_t hits)
{
    int32_t k, pw, ybot = PR_Y0 + PR_ROWS * PR_RH, yy = acc ? y : y + 1, h = acc ? PR_RH : PR_RH - 2;
    if (y < PR_Y0) {
        yy = PR_Y0;
        h = 1;
    } else if (y >= ybot) {
        yy = ybot - 1;
        h = 1;
    }
    if (hits < 2u) {
        cv_rect(x, yy, w, h, c);
        return;
    }
    pw = (w - (int32_t)hits + 1) / (int32_t)hits;
    for (k = 0; k < (int32_t)hits; k++)
        cv_rect(x + k * (pw + 1), yy, pw, h, c);
}

        }
    }

/* ACID's SOUND graph (spec §7): the filter's response at CUTOF / RESO (24 dB / octave, the RESO peak at the cutoff:
 * an approximation, as FILTER's), ENVMD's reach a dotted AMB line, 30 Hz .. 16 kHz across x 100..235 (15 px an
 * octave), +12 .. -32 dB (1 px a dB, 0 dB at y ACID_GY); under it the note's shape over 1 s (136 px): the amp gate
 * (DIM: GATE of a step at the tempo now) and the filter envelope falling over DECAY (HI) */
#define ACID_GY 14
#define ACID_EY 56                                      /* the shape's top; 36 px high */
static int32_t acid_cut_x(int32_t semis)                /* the cutoff MIDI 16 + semis -> px from 30 Hz (MIDI 23) */
{
    return clamp((16 + semis - 23) * 5 / 4, 0, 135);
}
static void graph_acid(const track_t *t, uint16_t c)
{
    const int16_t *p = &t->p[P_E0];
    int32_t cs = clamp(p[2], 0, 127) * 103 / 127, cx = acid_cut_x(cs), pk = -6 + clamp(p[3], 0, 127) * 18 / 127;
    int32_t x, y, py = 0, ex, gw, e = ENV1, kx = 65536;
    uint32_t k = acid_decay(p[1]), i;
    cv_rect(100, ACID_GY, 136, 1, C_LINE);                   /* 0 dB */
    for (x = 0; x < 136; x++) {
        int32_t dx = x - cx, db = dx <= -15 ? 0 : dx <= 0 ? pk * (15 + dx) / 15 : pk - dx * 24 / 15;
        y = ACID_GY - clamp(db, -32, 12);
        if (x)
            cv_line(99 + x, py, 100 + x, y, c);
        py = y;
    }
    ex = acid_cut_x(cs + clamp(p[4], 0, 127) * 48 / 127);   /* ENVMD: the cutoff at the note's start */
    if (p[4] > 0)
        for (y = 2; y < 46; y += 4)
            cv_rect(100 + ex, y, 1, 2, C_AMB);
