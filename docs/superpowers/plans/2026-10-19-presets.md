# Presets and Sound Banks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Voice presets in themed banks (Machinedrum, Classic 808 / 909, Modern / Plaits, User), browsed live with the
PRESETS encoder and in a list on a long EDIT, 128 user slots, every voice's default = its bank's first preset, the
Machinedrum bank read from the emulator's factory kits.

**Architecture:** A preset is `{model, 8 knobs, name}`; the factory banks are const tables (`preset_bank.h`), the
user bank a flash record in the unused `OBJ_UPRESET0 + 1`. One global preset id (factory banks in order, then the 128
user slots) drives the popup, the list and the project's per-track reference. `drum_set_model` loads the voice's
first preset; choke leaves the voices entirely. The Machinedrum content comes from a host-side readout in md-re.

**Tech Stack:** C (single translation unit firmware/src/felucca.c; host tests tests/*.c via tests/drum_host.h and
tests/ui_test.c), Python 3 / C tools in md-re, the Gearmulator MD Audio Unit.

**Spec:** `docs/superpowers/specs/2026-10-19-presets-design.md`

## Global Constraints

- A preset = MODEL + P_E0..P_E7 only. Banks in order: Machinedrum, Classic 808 / 909, Modern / Plaits, User.
- Up to 4 presets per voice; a Machinedrum voice with fewer distinct factory sounds gets fewer.
- No voice has a default choke group; a MODEL change or a preset load never changes P_CHOKE.
- Frozen files byte-identical (`python3 tools/check_untouched.py`; storage.c is frozen): user presets in
  `OBJ_UPRESET0 + 1`; MIDI LEARN's `OBJ_UPRESET0` untouched.
- Project format "FDRD" after "FDRC", older records converted on load (no preset, not edited, CHOKE as stored).
- Fidelity tests keep measuring at the old knob values: no fidelity metric, reference or threshold changes.
- Nothing from the emulator in the firmware but knob values; presets get Hortator's own names (<= 8 characters).
- Fixed point, no 64-bit divide (`grep -c divdi build/felucca.dis` = 0), no new ISR work.
- Never run tools/fm1_install.py, any installer or updater. Build: `export PYTHON=$PWD/.venv/bin/python
  PATH="$PWD/.venv/bin:$PATH"; DRUM_PACKAGE=1 ./build.sh` (retry up to 5x on "exec format error"). Suites:
  `sh tests/run_drum_tests.sh`, `sh tests/run_tests.sh` (gate 5 builds committed files: commit first).
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; explicit `git add` paths, never `.venv`.
- Temp files: /Users/evech/.claude/jobs/5fa7de86/tmp/presets/.

### Task 2: Preset core, user bank, project format, no default choke (firmware)

**Files:** Create `firmware/src/presets.c`, `firmware/src/preset_bank.h`, `tests/preset_test.c`. Modify
`firmware/src/core.h` (track_t: `uint16_t pre; uint8_t pre_ed;`), `firmware/src/felucca.c` (include presets.c after
dmodels.c), `firmware/src/drum_core.c` (`drum_set_model`), every `DM_*_DEF` with a non-zero choke field (-> 0),
`firmware/src/project.c` (FDRD), `firmware/src/main.c` or the main-loop hook MIDI LEARN's deferred save uses (the
deferred user save), `tests/run_drum_tests.sh`.

**Interfaces (Produces):**
- `typedef struct { uint8_t model; int8_t k[8]; char name[9]; } preset_t;` `#define PRE_NONE 0xFFFFu`
  `#define PRE_NUSER 128u` `enum { PB_MD, PB_CLASSIC, PB_MODERN, PB_USER, PB_N };`
  `static const char *const N_PBANK[PB_N] = {"MACHINEDRUM", "CLASSIC", "MODERN", "USER"};`
- `preset_bank.h`: `static const preset_t PRE_FACTORY[]; #define PRE_NFACT ...;` and `PRE_BANK_START[PB_N + 1]`
  (first id of each bank; user ids = PRE_NFACT .. PRE_NFACT + 127). **Initial content (until Task 5): one preset per
  model = its current defaults, named as the model, in its bank** (Machinedrum: the 21 MD voices; Classic and Modern
  per the spec's lists; ACID, SMPL in Modern).
- `static int preset_get(uint32_t id, preset_t *out)` → 1, or 0 for an empty user slot / bad id.
- `static uint32_t preset_bank_of(uint32_t id)`; `static uint32_t preset_first_of(uint32_t model)` (PRE_NONE if none).
- `static int preset_load(track_t *t, uint32_t id)` → 0 loaded (model + knobs, `t->pre = id`, `t->pre_ed = 0`, CHOKE
  untouched), -1 refused (empty slot, or ACID at `ACID_MAXTRK` on other tracks).
- `static uint32_t preset_step(const track_t *t, uint32_t from, int dir)` → the next loadable id in that direction
  (all banks in order, wrapping, skipping empty user slots and capped ACID); `from == PRE_NONE` → `preset_first_of`
  the track's model.
- `static void preset_touch(track_t *t)` → `t->pre_ed = 1` (called wherever a user edit changes P_E0..P_E7 / P_MODEL:
  the SOUND knobs, MIDI LEARN, the SMC knobs; not LFOs or MOTION playback).
- `static int preset_user_free(void)` (next free slot or -1); `static int preset_user_save(uint32_t slot, const
  track_t *t)` (auto name "<MODEL> NN", NN = slot + 1, two digits; written at once when stopped, else at the next STOP);
  `static void preset_user_delete(uint32_t slot)`; `static void preset_user_boot(void)`; `static void
  preset_user_tick(void)` (main loop: the deferred write once stopped, as MIDI LEARN's map).
- Flash record in `OBJ_UPRESET0 + 1`: magic "UPR1", 128 x {used, model, k[8]}; a record with another magic is ignored.
- `drum_set_model(t, mi)`: knobs from `preset_first_of(mi)` when it exists (else `edit[].def`), `t->pre` = that id,
  not edited, P_CHOKE untouched.
