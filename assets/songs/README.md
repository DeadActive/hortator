# Song excerpts (rhythm reference)

`rhythm_songs.json`: drum, bass and guitar notes of seven songs by the author's band, 30-second excerpts with tempo
map. It is the file `src/assets/rhythm_songs.json` of https://github.com/DaFum/neurotoxic-game, byte for byte
(git blob `3aaf708c9f0a2a9170d3f071f5b5c9440398a1bb`); the `.mid` and `.ogg` files it names stay there.

Used by `tools/songs_pattern.py` as a rhythm reference for GRIND and as a source of patterns for the FM-1.

Rights: the songs are the band's own. This data is **not** part of the GRIND MACHINE code and not under its GPL; it is
here as reference material, not as a licensed asset of the firmware, and it is not linked into any build or package.
